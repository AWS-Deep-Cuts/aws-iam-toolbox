管理者
1
API を呼び出す例: iam:GetPolicy
2

3
エラーメッセージを返すauthorization ID と
コンソールへのリンクを付ける
4

拒否の直後は、まだ照会できないことがある
プレビューの提供リージョンは us-east-1
5
authorization ID で照会する3 のリンクを開くか、API

  • リクエストのコンテキスト
  • 判定
