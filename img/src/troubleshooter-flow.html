拒否されるプリンシパル
IAM が自動で行う処理
管理者
1
API を呼び出す例: IAM の GetPolicy
2
ポリシーを評価して拒否する
3
エラーメッセージを返すauthorization ID と
Access Troubleshooter の URL を付ける
4
評価の詳細を記録する
  • エラーを返す処理とは別に、
    少し遅れて記録する
  • 拒否から少なくとも 24 時間は照会できる
  • 記録先は拒否が起きたリージョン。
    プレビュー中は us-east-1
5
authorization ID で照会する3 の URL を開くか、次の API を呼び出す
GetRequestAuthorizationDetails
必要な権限
iam:GetRequestAuthorizationDetails
6
評価の詳細を確認する
  • リクエストのコンテキスト
  • 判定
  • 一致したポリシー
  • 評価されたポリシー
